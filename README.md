\# 坦克迷宫（Tank Maze）



Unity 3D 课程作业 / 个人项目。



\## 🎬 演示视频



\[点击观看完整玩法演示](https://www.bilibili.com/video/BV1q8Yx6WEkX/)



\## 🎮 玩法简介



\- 驾驶坦克在复杂迷宫中探索，寻找通往撤离点的路径

\- 击碎可破坏墙体，发现隐藏捷径

\- 拾取随机掉落的道具（武器切换/防御增益/攻击增益/血量提升）

\- 通关时间将计入本地排名，支持反复挑战刷新纪录



\## 🛠 技术实现



\- \*\*引擎\*\*：Unity 2022.3.17f1c1 <DX11>

\- \*\*坦克控制\*\*：车身/炮台双轴分离控制（WASD + 鼠标）

\- \*\*子弹系统\*\*：两种子弹类型（炮弹：有下坠/大碰撞体；能量弹：无下坠/小碰撞体）

\- \*\*道具系统\*\*：5种可掉落道具，50%掉落概率

\- \*\*存档系统\*\*：基于PlayerPrefs的本地排名持久化存储

\- \*\*关卡设计\*\*：1个教学关卡 + 4个正式关卡，全部为手动精细设计



\## 🎯 操作说明



| 按键 | 功能 |

|:---|:---|

| W / S | 坦克前进 / 后退 |

| A / D | 坦克车身左转 / 右转 |

| 鼠标移动 | 炮塔独立瞄准 |

| 鼠标左键 | 开火 |



\## 🚀 运行方式



1\. 使用 Unity 2022.3.17f1c1 <DX11> 或更高版本打开项目

2\. 在 Project 窗口中打开 `Assets/Scenes/BeginScene.unity`

3\. 点击 Play 运行



> 首次运行会自动进入教学关卡，通关后解锁正式关卡。
